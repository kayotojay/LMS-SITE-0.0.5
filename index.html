STEP-BY-STEP SETUP
1
Go to supabase.com and sign in or create a free account — once logged in you will land on your dashboard.
2
Click New Organization and give it a name — organizations are free, call it anything.
3
Click New Project and set a Database Password.
⚠ SAVE THIS PASSWORD — you will need it if you ever migrate data. Choose a strong password and store it somewhere safe.
4
When prompted, make sure Enable Row Level Security (RLS) is turned ON — this keeps your data protected. The SQL you will run in step 6 already configures open policies for LMS.
5
Wait for the project to finish provisioning, then open it — usually takes 1–2 minutes. You will see a green status dot when it is ready.
6
In the left sidebar click SQL Editor — pick the correct script for your situation, copy it, paste into the editor, then press RUN.
⚠ WARNING — DESTRUCTIVE OPERATION
This script drops ALL LMS tables first, then rebuilds from scratch. Every server, member, project and chat message will be permanently deleted. Use this only on a brand-new project or when you deliberately want to wipe everything.

⚠ DO NOT MODIFY THE DATABASE MANUALLY

        
Do not rename, delete, or add columns to any LMS table in the Supabase Table Editor unless you know exactly what you are doing. Do not edit or rewrite the SQL scripts above unless you understand the full schema and all foreign key relationships. Do not drop RLS policies or disable Row Level Security — doing so exposes your entire database publicly.

        
The app expects a very specific table structure. Any manual changes that deviate from the script will cause errors or data loss that cannot be automatically recovered.
