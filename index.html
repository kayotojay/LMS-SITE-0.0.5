DATABASE SETUP
ONE-TIME SETUP — FREE, TAKES ~2 MIN
✓ DATABASE CONFIGURED
HOW TO SET UP (FREE)
1
Go to console.firebase.google.com
Sign in with Google → Click "Create a project" → name it anything → skip Analytics
2
In the left sidebar → Build → Realtime Database
Click "Create Database" → choose any location → start in test mode
3
Copy your Database URL from the top of the Realtime Database page
Looks like: https://your-project-default-rtdb.firebaseio.com
4
Paste it below — done! Share this URL with your team
Everyone on your team pastes the same URL to connect to the same server network
