DATABASE SETUP
One-time setup — free at supabase.com
✓ DATABASE CONFIGURED
STEP-BY-STEP SETUP
1
Go to supabase.com and sign in or create a free account
Once logged in you will land on your dashboard.
2
Click New Organization and give it a name
Organizations are free. You can call it anything — your name, team name, etc.
3
Click New Project and set a Database Password
⚠ SAVE THIS PASSWORD — you will need it if you ever migrate data. Choose a strong password and store it somewhere safe.
4
When prompted, make sure Enable Row Level Security (RLS) is turned ON
This keeps your data protected. The SQL you will run in step 6 already configures open policies for LMS.
5
Wait for the project to finish provisioning, then open it
Usually takes 1–2 minutes. You will see a green status dot when it is ready.
6
In the left sidebar click SQL Editor
Pick the correct script for your situation, copy it, paste into the editor, then press RUN.
⚠ WARNING — DESTRUCTIVE OPERATION
This script drops ALL LMS tables first, then rebuilds from scratch.
Every server, member, project and chat message will be permanently deleted.
Use this only on a brand-new project or when you deliberately want to wipe everything.
